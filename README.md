## C++ LAB


# 📌 Overview
The C++ Programming Laboratory is designed to provide practical exposure to Object-Oriented Programming (OOP) concepts and File Handling techniques using C++. This lab emphasizes writing structured, modular, and reusable programs that model real-world problems. Through hands-on experiments, students learn how to design classes, apply inheritance and polymorphism, and manage persistent data using files. The laboratory strengthens logical thinking, coding standards, and problem-solving skills essential for software development.

# 🎯 Objectives
To understand the fundamentals of Object-Oriented Programming in C++
To implement classes and objects for real-world problem solving
To apply encapsulation, inheritance, abstraction, and polymorphism
To develop programs using constructors and destructors
To perform file operations such as reading, writing, and appending data
To understand binary file handling and file pointers
To enhance modular programming and code reusability
To improve debugging skills and programming efficiency
